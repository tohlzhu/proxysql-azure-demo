如何判读这次实验

QPS ≠ 固定每秒切割

令牌桶按速率补充令牌，burst 允许短时突发。因此个别秒桶可能超过标称速率；长期吞吐与 429 更能体现约束。

并发：先等待，再拒绝

同一预定义查询由信号量限制执行并发。排队超过配置的超时时间返回 429（concurrency_limit_exceeded）；数据库或代理不可用才返回 503。请求延迟包含等待，API 未单独提供排队耗时。

本地计数与全局配额

local 每节点独立，双节点的总配额可能放大。distributed 通过 Redis 协调全局约束；请结合节点处理量确认流量确实到达多个节点。Redis 在 Demo 中仍可能是单点。

不同的故障域

ProxySQL 高可用不等于 MySQL HA。ProxySQL 原生规则负责查询治理，精确 QPS / 并发限流由应用代码实现。状态码 0 表示传输失败或客户端取消、未收到 HTTP 响应，不是服务端 503。恢复时间是首次不可用到下一次成功响应的间隔，未观测时为 null。故障场景必须由服务端预定义并经过管理授权，页面不会执行任意命令。
